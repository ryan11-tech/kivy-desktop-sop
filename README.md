# Tea SOP

Kivy desktop app for tea / milk-tea Standard Operating Procedure cards. Phone-shape window, single-user kiosk style.

## Run

```
pip install kivy
python main.py
```

Default PIN: `2222` (staff) / `1234` (admin).
